# Frero 🚀

Frero is a premium, next-generation social media platform built for immersive visual storytelling, real-time communication, and seamless community building. Combining the best elements of short-form video discovery, temporary updates, and instant messaging, Frero delivers a fluid, cinematic social networking experience.

Architected and refined using **Kiro** for specification-driven development, the entire ecosystem is fully containerized and ready to run with a single command.

## 🛠️ Tech Stack & Architecture

* **Frontend:** React.js, Tailwind CSS, Framer Motion
* **Backend:** Node.js, Express.js, Socket.IO
* **Database:** MySql
* **Orchestration & Tooling:** Docker, Docker Compose, Kiro, TypeScript
